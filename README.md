## Level 1: Check if a number is prime

File: prime_check.py

Description:  
This program asks the user to input a number and checks if it is prime.  
A number is considered prime if it is greater than 1 and cannot be divided evenly by any other number except 1 and itself.  
The program loops through numbers from 2 up to the given number and prints whether the number is prime or not.

Fibonacci Sequence Generator 🧮

This project generates the Fibonacci sequence using Python.

📌 What is Fibonacci Sequence?

The Fibonacci sequence is a series of numbers where each number is the sum of the two preceding ones:

0, 1, 1, 2, 3, 5, 8, 13, 21, ...

Formula:
F(n) = F(n-1) + F(n-2)

🚀 Features
Generate Fibonacci sequence up to n terms
Simple and beginner-friendly code
Uses loops (can also be extended to recursion)
